💾 Backup & Khôi phục dữ liệu
Dữ liệu lưu trong trình duyệt này. Backup thường xuyên để không mất dữ liệu khi đổi máy hoặc xóa cache.
ℹ️ Dữ liệu gồm: thói quen, tasks, journal, tài chính, mục tiêu. Không bao gồm timer Pomodoro đang chạy.
📤 Xuất dữ liệu (Export)
Tải file backup (.json)
Tải về máy tính → lưu vào Google Drive / iCloud / USB. Khi cần, import lại để khôi phục toàn bộ.
📥 Khôi phục dữ liệu (Import)
Dán JSON hoặc chọn file backup
Paste nội dung file .json vào ô bên dưới, hoặc chọn file từ máy tính.
📱 Dùng trên nhiều thiết bị
Cách đồng bộ giữa máy tính & điện thoại
1. Trên máy tính: nhấn Tải file backup → lưu vào Google Drive
2. Trên điện thoại: mở Google Drive → tải file .json về
3. Mở trang web Command Center trên điện thoại
4. Nhấn Backup → Import → chọn file .json vừa tải
💡 Tip: Backup mỗi tuần vào Chủ nhật khi làm weekly review
